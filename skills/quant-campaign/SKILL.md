# Quant campaign

Own the mission until a valid stop condition or a host boundary. Work inside the existing authorized session. Resolve the plugin root as `../..` from this file. Write only in the authorized research workspace.

Read the [campaign contract](references/campaign.md) before creating state or assigning research. It owns the ledger schema, breadth and depth protocol, budget rules, role prompts, and recovery. Read the shared [study contracts](../quant-research/references/contracts.md) and current [Codex](../quant-research/references/codex.md) or [Claude](../quant-research/references/claude.md) adapter. Study evidence and independent scientific gates remain authoritative.

Frame the original mission, meaningful scope, mechanism predictions, completion questions, resource permissions, wall ceiling, trial cap, and synthesis reserve. Ask for missing mission-specific constraints. A request for twenty hours does not authorize spending, data purchase, external services, or unrelated actions. Twenty hours is a ceiling; stop early when useful work is complete.

Freeze the charter with `tools/campaign.py start`. Run `view` before every new assignment and after compaction or handoff. Compare the strongest feasible alternative, a diagnostic or disconfirmation, and synthesis or replication before choosing work. Obtain required fresh independent challenges, then commit one bounded assignment with a stop condition. Workers write private artifacts; the coordinator alone changes the ledger and allocates trials with `trial` before any study registration. Continue through verified safe boundaries while the authorized host turn remains active.

Preserve failed, parked, negative, inconclusive, and unexecuted attempts. Parameter variants inherit a mechanism family. A repeated rationale is not new information. A blocked reviewer gates the dependent claim, while useful unrelated authorized work may continue. Before another narrow commitment, honor the actual breadth gate or a fresh capped depth exception.

Before losing context, close or preserve the current assignment, pending trial recovery, exact evidence refs, frontier, remaining budget, blockers, and next concrete action. Resume from the ledger and child inspections. Durable files do not wake the host or guarantee twenty hours of uptime. Use native continuation only when the actual host exposes it and the user has authorized it under its tool policy. Never create a launcher, replacement CLI session, daemon, global hook, or invented loop tool.
